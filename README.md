# Chart Editor GCD Plus

### A community-driven Friday Night Funkin' chart editor for mobile.

Chart Editor GCD Plus is a mobile-friendly chart editor project based on the original Chart Editor GCD.

The project aims to make chart creation more accessible on mobile devices, with a focus on usability, multi-engine compatibility, and a smoother charting experience.

---

##  Features

- Mobile-friendly chart editing.
- Friday Night Funkin' chart creation and editing.
- Planned support for multiple FNF engines.
- UI improvements and quality-of-life enhancements.
- Ongoing code cleanup and maintainability improvements.

> Features and compatibility may vary as development progresses.

---

## Development Status

Chart Editor GCD Plus is currently in development.

This project is being actively improved, and some features may be incomplete, experimental, or unavailable.

More improvements and compatibility updates are planned as development continues.

---

## Project Goals

- Improve the overall charting experience on mobile devices.
- Expand compatibility with different Friday Night Funkin' engines.
- Make the codebase cleaner, more modular, and easier to maintain.
- Introduce useful quality-of-life features for chart creators.
